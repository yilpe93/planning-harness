1. 문제 정의

```
[누구]가 [어떤 상황]에서 [무엇]을 하고 싶어 하지만 [무엇] 때문에 [어떤 불편]을 겪는다.
```

2. 고객 페르소나 (예시 3가지)

```ex
서울 마포구 34세 UX 디자이너 김유진, 10년차 3개월 전 결혼, 주 3회 야근,
건강검진에서 혈당 경고 받음, 월 20만원까지 건강에 쓸 의향, 인스타·토스·당근을
하루에 한 번씩은 열어봄
```

3. Journey Map(2의 페르소나 각 예시 마다 적용)

```참고자료
# Moments of Truth(MoT)

- 처음 10초 — 앱 열고 가치가 느껴지는 순간
- 첫 성공 — "Aha!" 하는 그 한 번
- 실패나 오류가 났을 때의
- 결제·구독을 누르는 직전
- 떠나려 할 때 마지막 인사
```

```템플릿
[역할] "서비스 디자이너 10년차"
[페르소나]
"""
(페르소나 예시)
"""

[요청]
[문제] 문제를 푸는 과정을 5단계 Journey로

[형식] 마크다운 표
단계 / 행동 / 생각 / 감정(1~5점)/ 접점 / Pain / Opportunity

[추가]
- MoT는 [MOT] 라벨
- 가장 큰 Pain은 [TOP] 라벨
- 마지막에 "핵심 1문장" 추가
- 감정이 1~2점 구간을 MVP 1순위로 표시
```

4. 아이디어 구상 (법적 문제되는 것 제외, 기능적 외부 요인 검토)

```참고자료
같은 문제를 여러 각도의 질문으로 다시 던지면 아이디어가 쏟아집니다
- 장애물 제거 각도
- 강점 극대화 각도
- 반대로 뒤집기 각도

HMW 01 재료 준비 단계를 없앨 수 있을까?
HMW 02 조리 시간 자체를 즐거움으로 만들 수 있을까?
HMW 03 혼자 먹는 저녁을 누군가와 연결할 수 있을까?
HMW 04 죄책감 대신 성취감으로 바꿀 수 있을까?
HMW 05 냉장고 재고를 자동으로 활용할 수 있을까?
HMW 06 건강을 게임처럼 만들 수 있을까?
```

```템플릿
[역할] "창업 5회 경험의 제품 기획자"
[문제] """ 1. 문제정의 """
[페르소나] """ 2,3 페르소나 + JTBD """
[제약]
- 초기 예산 1천만 원 이하
- 3주 안에 MVP 가능
- AI를 핵심 기능에 반드시 활용

[요청]
HMW 질문 6개 먼저 만들고
각 HMW마다 아이디어 2개, 총 12개
각 아이디어마다
- 서비스명
- 한 줄 설명 (40자)
- 타깃 사용 상황
- 가장 큰 차별점
- 주된 리스크를 표로
```

> 각 아이디어 마다 5,6번의 지표 or 근거가 있는 가설 및 유사 서비스 예시를 통해 방향 제시(이후 진행과정 병렬로 진행)

1. AARRR(모르겠거나, 정확하지 않다면 비슷한 서비스를 예시로 들어 근거와 방향 제시로 대체)

```ex
레시피봇은 1인가구 사용자가 일주일에 냉장고 재료로 완성한 요리 개수로 성공을 잰다
```

```North Star Metric 템플릿
[서비스명]은(는) [사용자]가 [기간 단위]에 [핵심 행동]을 몇 번 하는지로 성공을 잰다.
```

6. Aha Moment(모르겠거나, 정확하지 않다면 비슷한 서비스를 예시로 들어 근거와 방향 제시로 대체)
   - Acquisition [유입] - [어느 채널로 몇 명]
   - Activation [활성화] - [어떤 행동 후 Aha]
   - Retention [유지] - [D7 목표 %]
   - Revenue [수익] - [ARPU 또는 가격 모델]
   - Referral [추천] - [초대 동기와 예상 K]

```
Aha Moment의 3조건

구체적 — 몇 번, 몇 명, 몇 초 단위로 측정 가능
감정적 — "오 이거 편하네" 감탄이 나오는 지점
잔존과 상관 — 이걸 경험한 사람이 실제로 더 오래 남음
```

```ex
1인가구 사용자가 가입 후 10분 안에 냉장고 사진 1장으로 10분 레시피 1개를 받으면 "아 오늘 배달 안 시켜도 되겠다"를 느낀다
```

```템플릿
[사용자]가 가입 후 [시간 또는 단계] 안에 [구체적 행동]을 [횟수·수치] 경험하면 ["아 이거 좋네" 와 같은 감성적인 반응]를 느낀다
```

7. 사용자에게 아이디어를 선택하도록 질문(여러개 선택 가능)

8. 1-Pager PRD 산출

```템플릿
# [서비스명] 1-Pager v0.1
# 작성자 · 날짜

1. 한 줄 요약

2. 문제 정의

3. 타깃 페르소나 · JTBD
이름 / 나이 / 직업 / JTBD 한 문장

4. North Star Metric

5. Aha Moment

6. MVP 기능 (1~2개)
기능 1 — 한 줄 설명
기능 2 — 한 줄 설명

7. 안 할 것 (Out of Scope)
- v2 이후 / v3 이후

8. 성공 기준
D7 잔존 __% / Aha _%
CSAT _/5

9. 열린 질문
아직 답 못 낸 것 3개
```
