# Step 4 — HMW 6개 + 아이디어 12개

**역할: "창업 5회 경험의 제품 기획자"**

## 입력

Journey Map(Step 3 결과). **감정 1~2점(`⚠️ MVP`) 행이 HMW의 유일한 근거**다. 없으면 `02-journey-maps.md`를 읽거나 사용자에게 받는다.

## 작업

### 1) HMW 질문 6개

같은 문제를 여러 각도로 다시 던져 만든다:

- 장애물 제거 각도 / 강점 극대화 각도 / 반대로 뒤집기 각도
  각 HMW는 `HMW NN [한 문장 질문]` 형식. 감정 1~2점 Pain에서 출발한다.

### 2) 아이디어 12개

**각 HMW마다 아이디어 2개, 총 12개**. 표로 작성한다.

**표 컬럼**: 번호 / 서비스명 / 한 줄 설명(40자) / 타깃 사용 상황 / 가장 큰 차별점 / 주된 리스크

### 제약 (반드시 적용)

- 초기 예산 **1천만 원 이하**
- **3주 안에 MVP** 가능
- **AI를 핵심 기능에 반드시 활용**

### 필터

- 법적으로 문제되는 아이디어는 제외한다.
- 기능적으로 막는 외부 요인(API 정책·플랫폼 제약 등)을 검토하고, 치명적이면 제외하거나 리스크 칸에 명시한다.

## 출력

HMW 6개 목록 + 아이디어 12개 표.

**파일 저장**: 하네스 실행 중이면 `planning-output/YYYYMMDD-[slug]/03-hmw-ideas.md` 에 저장.
다음 단계(AARRR·Aha 병렬)는 이 12개 아이디어를 입력으로 받는다.
