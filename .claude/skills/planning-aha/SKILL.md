# Step 6 — Aha Moment 가설

**역할: "제품 분석가 7년차"**

> 하네스 전체 실행 중 12개 아이디어를 병렬 처리할 때는 `planning-idea-brief` 에이전트가 이 규칙을 적용한다. 이 스킬은 **단독/특정 아이디어 실행**용이다.

## 입력

선택된 아이디어 + AARRR의 Activation 항목. 없으면 `04-idea-brief.md`/`03-hmw-ideas.md`에서 가져오거나 사용자에게 받는다.

## 작업

### 1) Aha Moment 1문장 (필수 형식)

> `[사용자]가 가입 후 [시간] 안에 [구체적 행동]을 [횟수·수치] 경험하면 ["아 이거 좋네" 류 감성 반응]를 느낀다.`

예: "1인가구 사용자가 가입 후 10분 안에 냉장고 사진 1장으로 10분 레시피 1개를 받으면 '아 오늘 배달 안 시켜도 되겠다'를 느낀다."

### 2) Aha 3조건 자가 점검

- **구체적** — 몇 번·몇 명·몇 초로 측정 가능한가
- **감정적** — "오 이거 편하네" 감탄이 나오는가
- **잔존 상관** — 이걸 경험한 사람이 실제로 더 오래 남는가

각 조건을 한 줄씩 충족 근거와 함께 점검한다.

### 3) 온보딩 최단 경로 (단독 실행 시)

가입 → Aha까지 최소 단계 표 + 이탈 방어 체크포인트. (병렬 컴팩트 모드에서는 생략 가능)

## 출력

Aha 문장 + 3조건 점검 (+ 단독 실행 시 온보딩 경로).

**파일 저장**: 하네스 단독 단계 실행이면 `planning-output/YYYYMMDD-[slug]/04-idea-brief.md`에 해당 아이디어 블록으로 반영. 독립 실행이면 보여주고 저장 여부를 묻는다.
