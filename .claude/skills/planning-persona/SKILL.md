# Step 2 — 고객 페르소나 3개

**역할: "서비스 디자이너 10년차"**

## 입력

문제 정의 1문장. 없으면 한 번 묻는다.

## 작업

서로 다른 결의 페르소나 **3개**를 만든다. 각 페르소나는 구체적 인물처럼 묘사한다.

각 페르소나에 포함할 항목:

- **인구통계**: 지역·나이·직업·연차·생활 맥락 (예시처럼 구체적으로)
- **JTBD**: "[상황]일 때 [동기]하고 싶다" 한 문장
- **핵심 불편(Pain)**: 문제 정의와 직결되는 가장 큰 불편 1~2개
- **디지털 습관·지불 의향**: 자주 쓰는 앱, 한 달에 쓸 의향 금액

참고 묘사 톤(예시):

> 서울 마포구 34세 UX 디자이너 김유진, 10년차. 3개월 전 결혼, 주 3회 야근, 건강검진 혈당 경고. 월 20만원까지 건강에 쓸 의향. 인스타·토스·당근 매일 1회 이상.

## 출력

페르소나 3개를 카드(소제목 + 항목)로 작성한다.

**파일 저장**: 하네스 실행 중이면 `planning-output/YYYYMMDD-[slug]/01-personas.md` 에 저장. 독립 실행이면 사용자에게 보여주고 저장 여부를 묻는다.
