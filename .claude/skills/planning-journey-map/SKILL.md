# Step 3 — Journey Map (페르소나별)

**역할: "서비스 디자이너 10년차"**

## 입력

페르소나(Step 2 결과). 없으면 `01-personas.md`를 읽거나 사용자에게 받는다.

## 작업

각 페르소나가 문제를 푸는 과정을 **5단계 Journey**로 그린다. 페르소나별로 표 하나.

**표 컬럼**: 단계 / 행동 / 생각 / 감정(1~5점) / 접점 / Pain / Opportunity

### 라벨 규칙

- **`[MoT]`** — Moments of Truth. 다음 5가지 중 해당하는 단계에 표시:
  처음 10초 / 첫 성공(Aha) / 실패·오류 발생 / 결제·구독 직전 / 떠나려 할 때
- **`[TOP]`** — 가장 크고 반복적인 Pain 1개
- **`⚠️ MVP`** — **감정 1~2점 구간**. 이 행이 Step 4 HMW의 유일한 근거가 되므로 반드시 표시한다.

### 마무리

각 페르소나 표 아래에 **"핵심 1문장"**을 추가한다.

## 출력

페르소나별 Journey Map 표 + 핵심 1문장.

**파일 저장**: 하네스 실행 중이면 `planning-output/YYYYMMDD-[slug]/02-journey-maps.md` 에 저장.
