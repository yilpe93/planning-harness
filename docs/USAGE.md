# 기획 자동화 하네스 — 사용 설명서

> 이 저장소의 Claude Code 기반 기획 자동화 시스템 사용 가이드

---

## 전체 흐름

```
문제 정의 입력
    ↓
Step 2  페르소나 3개             → 01-personas.md
Step 3  Journey Map 3개          → 02-journey-maps.md
Step 4  HMW 6개 + 아이디어 12개  → 03-hmw-ideas.md
    ↓
Step 5·6  AARRR + Aha 가설 (12개 아이디어, 병렬 에이전트) → 04-idea-brief.md
    ↓
[사용자가 아이디어 선택]  ← 유일한 수동 개입
    ↓
Step 8·9  1-Pager PRD + 초안     → 05-prd.md
    ↓
최종 합본                        → [slug]-기획결과-전체.md
```

> Step 5·6는 12개 아이디어 전체에 대해 `planning-idea-brief` 에이전트를 **3개씩 4배치로 병렬 dispatch**하여 한 번에 산출한다. 사용자는 그 결과(지표·Aha 가설)를 보고 선택한다.

모든 결과물은 `planning-output/YYYYMMDD-[slug]/` 에 자동 저장된다.

---

## 빠른 시작 — 전체 자동 실행

```
문제 정의와 함께 다음 중 하나를 입력하면 8단계가 순서대로 실행된다:

"처음부터 끝까지 기획해줘"
"전체 기획 실행해줘"
"하네스 실행해줘"
"/planning-harness"
```

**예시 입력:**
```
30대 직장인이 월말에 카드값 고지서를 보고 나서야 지출을 파악하지만,
평소에 소비 습관을 기록하기 귀찮아서 가계부를 3일 이상 유지하지 못한다.
이 문제 처음부터 끝까지 기획해줘.
```

중간에 아이디어 선택만 한 번 응답하면 된다. 나머지는 자동으로 진행된다.

## 단계별 독립 실행

각 단계를 따로 실행하거나 특정 단계만 반복할 때 사용한다.

### Step 2 — 페르소나

**트리거 키워드**: "페르소나 만들어줘", "타깃 유저 정의해줘", "누가 쓸 것 같아?"

**필요한 입력**: 문제 정의 한 문장

**출력**: 3개의 페르소나 카드 (인구통계 · JTBD · 핵심 불편)

---

### Step 3 — Journey Map

**트리거 키워드**: "Journey Map 그려줘", "여정 지도", "Pain Point 분석", "UX 흐름"

**필요한 입력**: 페르소나 (Step 2 결과)

**출력**: 페르소나별 5단계 여정 표. 감정 1~2점 구간에 `⚠️ MVP` 자동 표시

**라벨 의미**:
- `[MoT]` — Moments of Truth (결정적 순간 5가지)
- `[TOP]` — 가장 크고 반복적인 Pain
- `⚠️ MVP` — 감정 점수 1~2점, HMW 질문의 원천

---

### Step 4 — HMW + 아이디어

**트리거 키워드**: "아이디어 뽑아줘", "HMW 만들어줘", "솔루션 브레인스토밍", "MVP 아이디어"

**필요한 입력**: Journey Map (감정 1~2점 행이 HMW의 근거가 됨)

**출력**: HMW 6개 (각도별) + 아이디어 12개 표 (서비스명 · 한 줄 설명 · 타깃 · 차별점 · 리스크)

**아이디어 제약** (항상 적용):
- 초기 예산 1천만 원 이하
- 3주 안에 MVP 가능
- AI를 핵심 기능에 반드시 활용

---

### Step 5 — AARRR 지표

**트리거 키워드**: "AARRR", "North Star Metric", "성장 지표", "그로스 지표"

**필요한 입력**: 선택된 아이디어 (서비스명, 타깃, 차별점)

**출력**: North Star Metric 문장 + AARRR 5개 지표 표 (목표값 · 측정 방법 · 참고 사례)

**수치가 불확실하면**: 유사 서비스 사례를 근거로 범위로 제시

---

### Step 6 — Aha Moment

**트리거 키워드**: "Aha Moment", "온보딩", "첫 성공 경험", "활성화 지점"

**필요한 입력**: 선택된 아이디어 + AARRR Activation 항목

**출력**: Aha Moment 문장 + 온보딩 최단 경로 표 + 이탈 방어 체크포인트

**Aha 문장 형식**:
```
[사용자]가 가입 후 [시간] 안에 [구체적 행동]을 경험하면 ["감성적 반응"]를 느낀다.
```

---

### Step 8·9 — PRD

**트리거 키워드**: "PRD", "기획서", "MVP 정의", "제품 요구사항", "기능 스펙"

**필요한 입력**: 모든 이전 단계 결과 (자동으로 파일 참조)

**출력**:
- **1-Pager PRD**: 한 페이지 요약 (한 줄 요약 · 페르소나 · NSM · Aha · MVP 기능 · 성공 기준 · 열린 질문)
- **PRD 초안**: 상세 문서 (기능 요구사항 표 · 불확실도 ★~★★★ 섹션별 표시)

---

## 출력 파일 구조

```
planning-output/
└── 20260601-가계부-직장인/          ← YYYYMMDD-[slug]
    ├── 01-personas.md               ← Step 2 결과
    ├── 02-journey-maps.md           ← Step 3 결과
    ├── 03-hmw-ideas.md              ← Step 4 결과
    ├── 04-idea-brief.md             ← Step 5·6 결과 (12개 아이디어 AARRR + Aha 가설)
    ├── 05-prd.md                    ← Step 8·9 결과 (선택된 아이디어)
    └── 가계부-직장인-기획결과-전체.md  ← 최종 합본
```

slug는 문제 정의에서 자동 추출된다 (핵심 키워드 2~3개, 소문자·하이픈 형식).

## 훅 (자동 동작)

`settings.local.json` 에 설정된 훅이 다음 동작을 자동으로 수행한다:

| 훅 | 동작 |
|----|------|
| `PostToolUse(Write)` | `planning-output` 경로에 파일 저장 시 `[기획 하네스] ✓ 저장: 파일명` 출력 |
| `Stop` | 세션 종료 시 `planning-output/` 아래 저장된 `.md` 파일 목록 출력. PRD(`05-prd.md`)까지 끝났는데 합본(`*-기획결과-전체.md`)이 없으면 ⚠️ 경고 출력 |

## 역할 설정 참고

각 단계에서 Claude가 사용하는 역할:

| 단계 | 역할 |
|-------|------|
| 페르소나 · Journey Map | 서비스 디자이너 10년차 |
| HMW · 아이디어 | 창업 5회 경험의 제품 기획자 |
| AARRR | 스타트업 그로스 해커 8년차 |
| Aha Moment | 제품 분석가 7년차 |
| PRD | SaaS PM 10년차 |

## 자주 묻는 질문

**Q. 아이디어 선택을 건너뛰고 싶어요.**
Step 4 직후 "1번 아이디어로 계속해줘" 처럼 바로 선택하면 된다. 선택지를 안 주면 하네스가 기다린다.

**Q. Step 4까지만 하고 싶어요.**
"페르소나부터 HMW까지만 해줘"라고 말하거나, Step 4 완료 후 아이디어를 선택하지 않으면 된다.

**Q. 특정 단계 결과가 마음에 안 들어요.**
해당 단계 키워드를 다시 말하면 그 단계만 재실행한다. 이전 파일은 덮어씌워진다.

**Q. 여러 아이디어를 동시에 진행하고 싶어요.**
"3번과 7번 아이디어 둘 다 진행해줘"라고 하면 각각 별도 파일 세트(`-아이디어A`, `-아이디어B`)로 처리된다.

**Q. 수치가 없어서 AARRR이 막막해요.**
비슷한 서비스의 초기 실적을 근거로 범위를 제시하는 방식으로 대체된다. 정확한 수치보다 방향 설정이 먼저다.
